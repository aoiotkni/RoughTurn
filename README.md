## Installation

1. Clone the repository: `git clone https://github.com/programmerbnd/RoughTurn.git`
2. `cd RoughTurn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure RoughTurn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
